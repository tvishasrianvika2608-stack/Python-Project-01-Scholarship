# Project 1: University Scholarship Allocation

## Problem Description
This project evaluates a student's eligibility for a university scholarship based on aggregate marks, subject-wise marks, attendance percentage, and annual family income.

## Programming Language
Python

## Concepts Used
- Variables and data types
- Conditional statements
- Logical operators
- User input and output

## Files Included

- `Screenshots/` – Code and output screenshots

## How to Run
1. Download the Python file.
2. Open it using Python or VS Code.
3. Run the program and enter the required student details.

## Conclusion
The program checks the given eligibility conditions and displays whether the student is eligible for the university scholarship.
